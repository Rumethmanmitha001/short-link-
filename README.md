
# URL Shortener DevOps Project

## Project Description
A web application that converts long URLs into short URLs.

## Technologies
- React.js
- Node.js
- Python FastAPI
- PostgreSQL
- Git and GitHub
- Docker
- Kubernetes
- AWS
- GitHub Actions
- Prometheus
- Grafana

## Project Features
- URL shortening
- URL redirection
- User authentication
- Click analytics
- Monitoring dashboard

## Project Goal
To develop, containerize, automate, deploy and monitor
a web application using DevOps practices.
